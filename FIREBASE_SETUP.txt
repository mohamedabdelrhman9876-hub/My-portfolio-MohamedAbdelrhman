FIREBASE SETUP

1. Use the existing Firebase project. Do NOT create a new Firebase project.
2. Keep the existing Firebase configuration in js/firebase.js.
3. Enable Authentication > Sign-in method > Email/Password.
4. Make sure Firestore Database is enabled.
5. Deploy firebase/firestore.rules in the existing Firebase project.
6. In firebase/firestore.rules replace YOUR_OWNER_UID with the Firebase Authentication UID of the portfolio owner.
7. The Contact form writes public messages to the messages collection. Only the owner UID can read those messages.
8. Do not put a Firebase Admin SDK key, service-account JSON, private key, or password in frontend files.
9. Run the site through a local web server such as VS Code Live Server. Do not open the HTML files with file://.

Important:
- A user can create an account and enter dashboard.html.
- The dashboard shows that signed-in user's Firebase Authentication information.
- Message reading is separately protected by Firestore Rules and is available only to YOUR_OWNER_UID.
- Total Users is intentionally not queried from the browser because exposing all user records is not a safe frontend pattern.
